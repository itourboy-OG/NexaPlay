# NexaPlay v1.12.0

This release gives NexaPlay a cleaner Windows 11-inspired interface and fixes the empty Installed and Downloads layouts.

- Adds rounded Windows 11 window chrome, navigation, controls, cards, search, and progress indicators.
- Updates the shell colors and spacing for a softer, more professional gamer-focused design.
- Replaces the duplicated Installed empty state with one clear message and a **Browse Games** action.
- Adds dedicated empty messages for Installed, Favorites, and search results.
- Makes the Downloads page use the available window width instead of a narrow centered column.
- Refreshes the download header and network/peak activity cards.
- Keeps all updates user-controlled: NexaPlay shows the update first and opens the normal visible installer only after approval.
