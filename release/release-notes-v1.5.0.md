NexaPlay v1.5.0 connects the SauceBoyz game library to GitHub.

### What is new

- Friends receive game additions, removals, metadata, artwork, and link changes through automatic catalog sync.
- The sidebar checks for new NexaPlay versions and displays **Update v... ready** when one is available.
- App installers download through the Downloads page with speed, ETA, completion time, and cancellation.
- Every app update installer must pass SHA-256 verification before it can launch.
- Owner Studio publishes catalog changes through the owner's signed-in GitHub CLI account; no owner key is placed in the player.

### Install

Download `NexaPlay-Setup-v1.5.0.exe` and run it. The installer is self-contained and installs the player app for the current Windows user.

SHA-256: `820E127B0363D7890BC9F23D0F2D64B0C208A8EDA81301AF3F254546EF90CAF7`

The installer is currently unsigned, so Windows SmartScreen may display **Unknown publisher**.
