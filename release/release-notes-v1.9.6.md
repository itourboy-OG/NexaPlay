# NexaPlay 1.9.6

- Added **Uninstall Game** to installed game pages with protected manifest verification and immediate Play-state refresh.
- Uninstalled managed game folders are moved to the Recycle Bin and remain available for re-download from the catalog.

- NexaPlay update artwork now fits cleanly inside active, queued, and history rows.
- Update checks now bypass stale GitHub manifest caches so newly published versions appear immediately.
