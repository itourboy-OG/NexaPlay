# NexaPlay 1.9.0

- Redesigned gamer sidebar with a larger profile card, icon-backed navigation, stronger selected states, and the new Ready Up · Game On identity.
- New first-run setup and quick-start guide with clear app instructions and a Skip button.
- Every player can choose a local username and optional profile picture; personal profile data is never bundled into the shared installer.
- Full Game, Update, and Online Fix packages now work independently.
- Players who already own a game can choose its folder and apply only the available update or Online Fix without installing the base game through NexaPlay.
- App updates remain fully manual: NexaPlay notifies, asks before downloading, verifies the installer, and asks again before opening the normal visible setup wizard.
