NexaPlay v1.6.1 adds a full game-specific PC performance check through Technical City.

- Every game page now has a `FULL FPS CHECK — TECHNICAL CITY` button.
- NexaPlay automatically builds the matching Technical City game link from the game title.
- PEAK opens its Technical City PEAK page and Forza Horizon 6 opens its dedicated Forza page.
- Technical City provides the maintained CPU/GPU ranking, recommended-settings result, and FPS estimates.
- NexaPlay keeps its instant private local check for Windows, RAM, and free storage.
- The PC profile window also links to the selected game's Technical City page.

Download `NexaPlay-Setup-v1.6.1.exe` and run it. Existing settings, installed games, favorites, and PC profile are preserved.
