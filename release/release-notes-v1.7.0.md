# NexaPlay 1.7.0

- Creator Studio now saves every add, edit, duplicate, import, metadata refresh, and removal automatically.
- Save gives a clear confirmation without closing Studio.
- Publish sends the saved catalog to GitHub and shows a visible success or failure notification.
- Done always completes a local save before closing and stays open if saving fails.
- Owner drafts now use a separate local catalog so Player syncing cannot overwrite unpublished work.
- Removed Optional online publishing and renamed the add action to + Add Games.
- Player checks for catalog changes every 30 seconds and when focused, while avoiding unnecessary page refreshes when nothing changed.
