# NexaPlay 1.9.7

- Replaces the oversized game-page action stack with compact Play, Favorite, and More controls.
- Moves Technical City, reporting, and installed-game deletion into the More menu.
- Removes the redundant Download Options shortcut while keeping the full Download Center available.
- Permanently deletes confirmed NexaPlay-managed game installs instead of moving them to the Recycle Bin.
- Refreshes installed state immediately after deletion so Play disappears as soon as the game is removed.
