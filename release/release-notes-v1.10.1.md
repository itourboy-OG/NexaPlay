# NexaPlay v1.10.1

- Trailer and gameplay searches now resolve to the actual YouTube video and start it automatically inside a clean embedded player instead of showing a search/browser page.
- Playback starts muted, like a modern game storefront, so autoplay is reliable; use the normal player control to turn sound on.
- Embedded YouTube playback includes its normal play, volume, timeline, keyboard, and fullscreen controls.
- Replaced the standard WPF WebView with the composition control so the video cannot draw over NexaPlay's status bar, toasts, or other native UI.
- Capped library, game-detail, and download content for cleaner fullscreen layouts on 34-inch ultrawide displays.
- Community reports now include the game title and the player's chosen NexaPlay display name in Owner Studio.
- Shared ratings still store one current vote per Player installation; reports and ratings become shared as soon as the private Community service is hosted and connected.
