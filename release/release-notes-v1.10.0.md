# NexaPlay v1.10.0

- Browse large catalogs with 12 games per page, numbered page controls, and a compact filter dropdown.
- Filter by all games, single-player, multiplayer, co-op, recently updated, or updates available.
- Downloads now show real network and peak speeds without the misleading disk-status label.
- Owner Studio can add one optional, owner-named package such as an English Language Pack. Empty packages stay hidden.
- Package sizes accept B, KB, MB, GB, or TB, with automatic host size detection when supported.
- Steam review scores are clearly separated from NexaPlay community votes.
- Ratings, confirmations, errors, compatibility results, and problem reports use polished in-app UI instead of Windows message boxes in Player.
- Owner Studio can privately review reports after the NexaPlay Community server is connected.
- Steam metadata now fills a Steam trailer when available and adds safe YouTube trailer/gameplay searches as fallbacks.
- Installed status is clearly green or red, and the AMD Radeon RX 9060 XT physical-GPU detection remains verified.
