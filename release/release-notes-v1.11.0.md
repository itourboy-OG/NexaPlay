# NexaPlay v1.11.0

- Removes the offline-only NexaPlay rating panel while keeping Steam review stars and counts.
- Hides Report a Problem until a working Community service is connected.
- Adds automatic official Steam update checks to Creator Studio.
- Adds an Updates available filter and an Official update status column.
- Avoids false alerts from calendar dates, previews, and incompatible version formats.
- Keeps update checking informational only: catalog versions and download links are never changed automatically.
