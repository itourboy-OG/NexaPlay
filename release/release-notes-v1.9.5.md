# NexaPlay 1.9.5

- Added **Uninstall Game** to installed game pages.
- Uninstall verifies the NexaPlay game manifest and only removes the matching managed folder inside the configured library.
- Deleted games are moved to the Recycle Bin when possible, and the library refreshes immediately so **Play** disappears.
- Finished app updates no longer remain visible as active downloads or leave a stale Downloads badge.
- NexaPlay update artwork now fits cleanly inside active, queued, and history rows.
